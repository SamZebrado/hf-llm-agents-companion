一个代表性例子

logit 到底是什么？

Logit 是模型对每个候选类别或 token 给出的原始分数。它还不是概率。Softmax 会把一组 logits 转成概率分布。

Temperature 做的事，就是在 softmax 之前重新缩放这些 logits：温度低，分布更尖；温度高，分布更平。

cat  = 4.0
dog  = 3.0
car  = 1.0

p = softmax(logits / T)
