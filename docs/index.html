Hugging Face LLM & Agents 学习笔记

把课程中容易一带而过、但实际学习时会卡住的问题整理下来：术语、机制、数值例子、常见误解和实践踩坑。

这份页面怎么用

可以从头读，也可以把这个页面或仓库交给自己的 AI / Agent，当作一份已经整理好的背景资料。遇到课程里的概念时直接问它，模型可以先从这里找到现成解释、误区和例子，再继续回答。这样即使使用较小、较便宜的模型，也能少走一些重复推理和补背景的弯路。
